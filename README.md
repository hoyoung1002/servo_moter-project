# Raspberry Pi Pico 버튼식 PWM 서보 과제

`main.py`는 Raspberry Pi Pico의 MicroPython 환경에서 버튼을 한 번 누르면 서보가 0도에서 180도까지 부드럽게 이동하고, 이동 각도에 비례해 LED 밝기를 조절함.

## 핀 구성

| 부품 | Pico GPIO | 연결 방법 |
| --- | --- | --- |
| 버튼 | GP15 | 버튼의 반대쪽을 GND에 연결하며 내부 풀업을 사용함. |
| 서보 신호 | GP16 | 서보의 신호선을 GP16에 연결함. |
| LED | GP25 | Pico 내장 LED를 사용함. |

## 동작

- 실행 직후 서보는 0도, LED 밝기는 0.0(OFF)으로 초기화됨.
- 버튼은 40ms 동안 안정된 뒤 눌림 이벤트를 한 번만 인식함.
- 이동 중에는 버튼 재입력을 무시하고, 15ms마다 1도씩 증가시켜 약 2.7초 동안 이동함.
- LED 밝기는 `각도 / 180.0`으로 계산한 0.0~1.0 비율을 PWM 듀티로 적용함.

## 전원 및 안전

- 서보는 Pico의 3.3V 핀이나 USB 전원에 직접 연결하지 말고, 서보 정격에 맞는 별도 전원을 사용함.
- 별도 서보 전원을 사용할 때 Pico GND와 서보 전원 GND를 반드시 공통으로 연결함.
- 서보 신호선은 Pico GPIO에 연결하되, 서보 전원선은 GPIO에 연결하지 않음.
- 외부 LED를 사용할 경우 LED에 직렬 저항을 추가하고, GP25는 내장 LED 사용을 전제로 함.

## 업로드

Thonny에서 Raspberry Pi Pico를 MicroPython 장치로 선택하고 `main.py`를 Pico의 루트에 저장하면 부팅 후 자동 실행됨.
